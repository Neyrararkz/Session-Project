PostgreSQL хранит структурированные сущности: пользователей, роли, друзей, посты, клубы.
MongoDB хранит гибкую коммуникационную часть: личные, групповые и клубные чаты, а также сообщения.
MongoDB используется для хранения сообщений и чатов, потому что это потоковые данные, которые удобно хранить документами. 

Database: itstep

Collection: chats
Назначение: хранит личные, групповые и клубные чаты.

Поля:
_id — ObjectId чата
type — тип чата: direct, group, club
name — название группового/клубного чата
description — описание чата
image_url — картинка чата
club_id — id клуба, если это чат клуба
member_ids — массив id участников из PostgreSQL
last_message — последнее сообщение
last_message_at — время последнего сообщения
created_at — дата создания чата

Collection: messages
Назначение: хранит сообщения чатов.

Поля:
_id — ObjectId сообщения
chat_id — ObjectId чата
sender_id — id пользователя из PostgreSQL
text — текст сообщения
created_at — дата отправки
read_by — массив id пользователей, которые прочитали сообщение

Связь между PostgreSQL и MongoDB осуществляется через id пользователей. В MongoDB не дублируются полные данные пользователей, а хранятся только их идентификаторы. При отображении чатов backend получает пользователей из PostgreSQL по member_ids и sender_id.
